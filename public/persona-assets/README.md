Four raw screenshot copies from `admin input/OGCupid/` live here so Render serves them on the same origin. The source files are preserved unchanged. The live quiz crops artwork using SVG viewBox dimensions from `archive/dating-personas/result-recovery.json`.

The Backrubber, The Intern and The Bachelor have only small *exact-opposite* portraits so far; their images are classified accordingly. Original standalone GIF files are **not** recovered.

`vapor-trail.webp`, `sudden-departure.jpg`, `manchild.webp`, and `slow-dancer.png` are screenshot sources, not finished portraits.
