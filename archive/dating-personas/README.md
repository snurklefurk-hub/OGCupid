# Dating Persona Test

All 32 characters, their descriptions, artwork references, exact opposites and any available *Consider* / *Always Avoid* recommendations live here.

- `restored-descriptions.json`: character names and description paragraphs.
- `result-recovery.json`: visual assets, crop coordinates, opposite types and recommendation lists.
- `original-artwork/`: artwork assets.

When adding character copy, preserve the wording and paragraph breaks. The quiz can show a custom description when a character's full text is not yet entered.
