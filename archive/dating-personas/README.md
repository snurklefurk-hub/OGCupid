# Original Dating Persona material

**Scope:** 32 characters from the old OkCupid Dating Persona Test, 16 four-letter types with separate man/woman results.

The JSON file contains period text transcriptions only for results with material available in OG Cupid. "transcribed" is not a statement that the original site HTML or original image bytes were recovered.

The three-panel WebP sprite contains **screen-cropped artwork** from user-provided historical screenshots (Genghis Khunt at panel 0, The Peach at panel 1, The Playstation at panel 2). It does not contain the original standalone character GIF files.

**Reference sources:** [2016 Reddit retrospective](https://www.reddit.com/r/OkCupid/comments/4bwkcw/retro_take_the_okc_dating_persona_test/), and screenshots supplied in the OG Cupid Project. Attribution and context are tracked per record. Some records were also supplied as direct historical text by the user.

Please verify historic copy against the earliest available source before changing punctuation or marking a text verbatim-canonical; normal transcription can preserve minor typos and line-break differences.

**Original question bank:** not recovered. **Original scoring:** not recovered. **OG Cupid revival quiz:** 28 newly authored questions with its own scoring logic.
