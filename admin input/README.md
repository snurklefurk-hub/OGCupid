# Admin Input — Drop Zone

This is the OG Cupid research intake folder. Drop old OkCupid screenshots, archived web pages, quiz text, GIFs, documents, and other research leads here using GitHub Desktop or GitHub's website.

## Workflow
1. Copy files into `admin input/` in your local clone of this repository.
2. Commit and push to `main` using GitHub Desktop.
3. In the OG Cupid chat, say **"Check admin input"** (optionally include the commit SHA or filenames).
4. The assistant will inspect newly committed materials, separate confirmed historical originals from references/reconstructions, document provenance, and propose or apply appropriate changes to `archive/` and the website.

## Good additions
- Original artwork and historical screenshots (PNG, JPG, GIF, WebP)
- Original Dating Persona results, descriptions, and questions
- Saved public webpages, PDF documents, and exported test XML
- A short `sources.txt` alongside files with source links, dates, and context when known

## Important
- **This repository is public.** Do not commit passwords, API keys, personal documents, private communications, private dating profiles, or other sensitive data.
- This folder is **not automatically monitored**. Ask the assistant to review it after pushing a commit.
- Please avoid renaming original files if possible; filenames and source URLs help establish provenance.
- Files can remain here as unprocessed intake until they're reviewed. `archive/` is the curated historical collection.
